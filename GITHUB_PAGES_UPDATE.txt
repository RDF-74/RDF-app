Detailing Manager v3.7 β1
GitHub Pages更新手順

1. このZIPを展開する
2. GitHubのRDF-appリポジトリを開く
3. リポジトリ直下へ以下のファイルを上書きする
   ・index.html
   ・sw.js
   ・manifest.webmanifest
   ・photo-store.js
   ・notifications.js
   ・push-config.js
   ・icon-192.png
   ・icon-512.png
4. Commit changesで更新を確定する
5. GitHub Pagesの反映後、Safariを一度閉じてページを開き直す

v3.7 β1は、写真をIndexedDBの専用領域へ保存し、以前の写真を初回起動時に自動移行します。
画像18枚、メーカー別300商品カタログ、仕上がり方向対応のぴったりケミカル診断、Green Star使い方・希釈ガイドはindex.htmlに内蔵しています。
assetsフォルダをGitHubへ追加する必要はありません。

メンテ通知について
・通知はiPhoneのホーム画面へ追加したアプリから有効にします
・通知サーバー未設定でも、アプリを開いた時の通知とバッジを利用できます
・アプリを閉じている時も届くようにする場合は、PUSH_NOTIFICATIONS_SETUP.txtの初回設定を行います

画像が古い表示のままの場合
・Safariの更新ボタンを押す
・ホーム画面から起動している場合は、アプリを完全に閉じて再起動する
・GitHub Pagesの反映まで数分待つ
